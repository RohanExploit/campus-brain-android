# DBATU Old (Pre-NEP) Pattern — Subject Reference: Computer Engineering + AI/AIML/AIDS

Reference data for the RAG corpus. Covers students admitted AY2022-23 or before
(old/CBCS pattern; NEP applies from AY2023-24 admits onward at DBATU). Subject codes here
match codes present in this project's own `student_subjects` table (verified 2026-08-09).

Sources (official DBATU, Dr. Babasaheb Ambedkar Technological University, Lonere):
- Computer Engineering, WEF 2021-22: https://dbatu.ac.in/wp-content/uploads/2021/07/Revised-Computer-Engg-Syllabus-wef-2021.pdf
- AI / AIML / AIDS, T.Y. WEF 2022-23: https://dbatu.ac.in/wp-content/uploads/2022/09/Third-Year-ARTIFICIAL-INTELLIGENCE-MACHINE-LEARNING-ARTIFICIAL-INTELLIGENCE-DATA-SCIENCE-ARTIFICIAL-INTELLIGENCE.pdf

## Prefix → branch/department key
- `BTCO*` = Computer Engineering (core `C`, elective `E`, lab `L`, mini-project `M`, seminar `S`, field-training `F`)
- `BTAI*` = Artificial Intelligence / AI-ML / AI-DS (core `C`, elective `PE`/`OE`, lab `L`, mini-project `M`, internship `P`)
- `BTHM*` = Humanities & Social Science / Management elective — shared across branches, not branch-specific
- `BTBS*` = Basic Science — shared, common first year
- `BTES*` = Engineering Science — shared, common first year

## Note on `exam_results.department` derivation
A student's department/branch is inferable from which prefix family their core (`*C*`)
subject codes belong to: rows with `BTCOC*` codes → Computer Engineering; rows with
`BTAIC*` codes → Artificial Intelligence/AIML/AIDS. `BTHM*`/`BTBS*`/`BTES*` codes are
shared electives and carry no department signal on their own.
